# masjid-3d-model
from floor plan to 3d digital model :)

## Proposed Masjid & Mawaid — 3D Model

An interactive 3D model of the proposed Masjid & Mawaid at 3812 Barney Rd, Chantilly, Virginia.

## Files

| File | What it is |
|---|---|
| `index.html` | The interactive model. Open it in any web browser (needs an internet connection to load the 3D library). |
| `masjid-model-builder.js` | The code that builds the model, with comments explaining each part. |
| `Masjid-Mawaid-Barney-Rd.glb` | The 3D model file at real-world scale (meters) for Blender, Windows 3D Viewer or SketchUp. |

## How it was made

- Rooms are measured from the architect's floor plans (sheet 05, rev 09).
- The parking lot, road and existing building are traced from aerial imagery.
- The drop-off circle, entry plaza, fence, gate, ramp and landscaping are proposed.
- The upper floor is shown open because its layout wasn't provided.
